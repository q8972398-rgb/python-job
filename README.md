# LabSpace · 帽子云部署版本

实验室设备预约与故障管理交互 Demo。全部业务数据为虚构演示素材，数据仅保存在每位访客自己的浏览器中。无需接入数据库、校园服务或第三方 API。

`site/` 是已构建的静态产物。入口为 `site/index.html`，内部页面采用 Hash 路由，直接分享和刷新 `/#/devices`、`/#/bookings/...` 不依赖服务器重写规则。

帽子云创建静态网站时选择「Git」部署来源，填写公开仓库 `https://github.com/q8972398-rgb/python-job.git` 和部署分支 `labspace-demo`，根目录留空，构建命令为 `tar -xzf labspace-demo.tar.gz`，输出目录为 `site`。构建包中保留了完整的 `site/` 文件夹层级，此仓库直接提供构建产物，无需下载 npm 依赖。

本项目不含账号密码、API 密钥、原始 PRD、Axure 文件或本机路径。上传的网页内容与已发布的虚构 Demo 一致；该版本仅为通用静态托管调整路由。

上线后须实际打开平台返回的 HTTPS 域名，检查首屏、设备详情、预约入口、子页面刷新和无登录访问，再替换简历入口及二维码。
